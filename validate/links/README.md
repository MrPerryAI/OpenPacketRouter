# validate/links

Link shaping (token bucket) against Linux's `tbf` qdisc, frame for frame: `run_kernel_links.py` compares the result, the frames on every cable direction and the frames each shaped interface dropped. `results.md` is generated by CI.

The `tbf-stp-*` cases put spanning tree on a shaped cable. Their first action is marked `"warmup": true`: it runs on both sides to get past the bridge start-up but its window is **not compared**, because the number of hellos in a window that starts at start-up depends on the phase of the kernel's hello timer. The next action is exactly two hello periods long and is compared exactly (frames and drops).
